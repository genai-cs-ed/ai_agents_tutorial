Your recipe

Plain text, ready to copy and paste.

Goal: Review each student's lab submission against the rubric and write up how the rubric applies to it.

Context: You are a teaching assistant. I will give you a rubric and the students' submissions, and you need to apply the rubric to each submission.

Input: The rubric, and a folder of student submissions. Each student's submission is in its own sub-directory.

Steps:

  1. Review the rubric.
  2. Each student's submission is in its own sub-directory. Work through them one at a time.
  3. Apply the rubric to each student's submission.
  4. To compile a submission, run "make" on this system.
  5. Run the executable that make produces (most likely named lab0).
  6. Review the code as the rubric describes, and judge the quality of the work for each rubric category.
  7. Create a review.md file with specifics of how each rubric category was applied.
  8. At the end of review.md, give examples where the work was not perfect, according to the rubric.

Output: A review.md file for each student's submission. It shows how each rubric category was applied, with specifics. At the end of the file, it gives examples where the work was not perfect.

Rules: Apply the rubric as written and do not add criteria of your own. Do not change any student's files. If a submission does not compile or run, say so in its review and review what you can from the code. If anything in the rubric is unclear, ask me instead of guessing.
